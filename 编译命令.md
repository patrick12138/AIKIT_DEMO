# AIKITDLL编译命令

## MSBuild编译命令
```powershell
cd c:\AIKITDLL; & "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\amd64\MSBuild.exe" AIKITDLL.sln /p:Configuration=Debug /p:Platform=x64 /verbosity:minimal
```

## 说明
- 使用Visual Studio 2022的MSBuild工具
- 编译配置：Debug
- 平台：x64
- 输出详细度：minimal（最小化输出）

## 其他有用命令
```powershell
# 清理项目
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\amd64\MSBuild.exe" AIKITDLL.sln /p:Configuration=Debug /p:Platform=x64 /t:Clean

# 重新编译
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\amd64\MSBuild.exe" AIKITDLL.sln /p:Configuration=Debug /p:Platform=x64 /t:Rebuild
```
